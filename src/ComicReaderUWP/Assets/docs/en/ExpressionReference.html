Expression Reference

1. Variables

%tagMatch all tags in a comic.
%titleMatch title 1 or title 2.
%title1Match title 1.
%title2Match title 2.
%ratingMatch rating. For example: 100 represents 5 stars, -1 represents no rating.
%completion_stateComic completion state (0 - Unread, 1 - Reading, 2 - Completed).
%progressreading progress, in percentage. For example: 50 represents 50%.
%page_countTotal pages.
%release_dateMatch release date. Formatted as YYYY-MM-DD HH:MM:SS; empty when unset, so a bare %release_date matches only comics that have one.
Comparands may be a full date and time, or a partial date covering a period:
2026 or "2026" - The whole year 2026.
"2026-1" or "2026/1" - January 2026.
"2026-1-2" or "2026/1/2" - January 2, 2026.
Operators apply to that period rather than to the text:
%release_date = 2026 - Within 2026.
%release_date >= 2026 - From the start of 2026.
%release_date > 2026 - After the end of 2026.
%release_date < "2026-1" - Before January 2026.
%release_date <= "2026-1-2" - On or before January 2, 2026.
%release_date in (2026, 2027) - Within 2026 or 2027.
A full date and time, or anything that is not a date, is compared as plain text.

2. Variable operators

=Equal. For example: %title = "This is a title"
>Greater than. For example: %rating > 3
>=Greater than or equal.
<Less than.
<=Less than or equal.
... IN (...)Contained by. For example:
%rating in (3, 4, 5) - Match those comics whose ratings are within 3, 4 and 5.
%tag.language in (languageA, languageB) - Match those comics whose "language" tag category contains "languageA" or "languageB".
(authorA, authorB) in %tag.authors - Match those comics whose "authors" tag category contains both "authorA" and "authorB".
apple in %tag - Match those comics which contains tag "apple".

3. Logic operators

ANDLogic and. For example: %tag.fruit = apple AND %title = "I have an apple"
ORLogic or. For example: %title1 = "Apple is OK" OR %title2 = "Orange is also OK"
NOTLogic not. For example: NOT %tag = "hide this"

4. Parentheses

By default, operators will be evaluated from left to right. Use (...) to elevate the priority of included expression. For example:

%tag.author = abc AND (%tag.language = langA OR NOT %tag.lang = langB)

The evaluation will be performed in the following order:

1. NOT %tag.lang = langB ==> Result1

2. %tag.language = langA OR Result1 ==> Result2

3. %tag.author = abc AND Result2 ==> Result3
